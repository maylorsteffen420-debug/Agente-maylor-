# MAYLOR AI — integração Gemini

Este pacote contém a interface MAYLOR AI atualizada e um backend Python que conecta o chat ao Google Gemini 2.5 Flash.

**A integração está preparada, mas ainda não está publicada nem conectada à sua chave.** Para funcionar online, hospede `backend/` em um serviço Python, configure `GEMINI_API_KEY` como secret no servidor e informe a URL do backend na aba **Configurar IA** do app.

Consulte `backend/README.md` para os passos completos. Não compartilhe sua chave Gemini e não a coloque no HTML.
